⚡ Quick Reference

Start Local Server:
python3 -m http.server 8080
Then open: http://localhost:8080/editor.html
Game Controls:
Arrow Keys - Move Robbo
X - Shoot
ESC - Pause
Editor Tools:
✏️ Draw - Place tiles
🧹 Erase - Remove tiles
🪣 Fill - Flood fill areas
🎯 Pick - Copy tiles from map
